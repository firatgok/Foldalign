# Foldalign – Hasta Klasörü Düzenleyici

Ortodonti / şeffaf plak tedavisi hasta klasörlerini tek sürükle-bırakla düzenler:

```
Hasta Klasörü\
  Başlangıç\       <- en erken tarihli fotoğraflar
  1.Refinement\    <- refinement klasörleri tarihe göre numaralanır
  2.Refinement\       ("refaynıt", "rifaynıt" gibi yazımlar da tanınır)
  Bitim\           <- elle doldurulur
  Restoratif\      <- elle doldurulur
  Pan\             <- panoramik röntgenler
  CBCT\            <- CBCT / DICOM klasörleri
```

## İndirme

En son sürüm: **[Releases](../../releases/latest)** sayfasından `Foldalign.exe` dosyasını indirin.
Kurulum gerekmez; dosyayı istediğiniz yere koyup çift tıklayın.

- İlk açılışta Windows SmartScreen uyarı verirse: *Daha fazla bilgi → Yine de çalıştır*.
- Program açılışta yeni sürüm olup olmadığına bakar ve tek tıkla kendini günceller.
- Pencereden "Klasöre sağ tık menüsünde göster" kutusunu işaretlerseniz Gezgin'de klasöre sağ tıklayıp
  *Foldalign ile düzenle* diyebilirsiniz.

## Kullanım

1. Hasta klasörünü pencereye bırakın.
2. Önizlemeyi kontrol edin (ne nereye gidecek, hangi tarihe göre).
3. **Düzenle (Uygula)** deyin. Dosyalar silinmez, yalnızca taşınır; **Son İşlemi Geri Al** ile geri alınır.

Bu depo yalnızca sürüm dosyalarını barındırır.
